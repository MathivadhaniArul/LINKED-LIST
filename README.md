# Mastering Linked Lists 

A specialized repository tracking my deep dive into Linked List structures, pointer manipulations, and memory management, started during my first year of college to build a rock-solid foundation in software engineering.

## Repository Directory
The repository is systematically organized by list architecture:
*   `/Singly_Linked_List` - Basic nodes, traversal, and linear manipulations.
*   `/Doubly_Linked_List` - Two-way pointer traversals and bidirectional operations.
*   `/Circular_Linked_List` - Ring structures, boundary handling, and loop tracking.
*   `/Advanced_Problems` - Complex intersection, sorting, and optimization challenges.

##  Core Operations Implemented
For each type of list, I have built the following foundational mechanics from scratch:
*   **Insertion**: At the head, tail, and any arbitrary position.
*   **Deletion**: Removing nodes by value, position, or pointer references.
*   **Search**: Linear lookup, middle element detection, and $k^{th}$ node finding.
*   **Utility**: Reversing a list (iterative & recursive), cloning, and merging.

##  Key Algorithmic Patterns Solved
This repository moves past basic operations to tackle advanced patterns, including:
*   **Two-Pointer Techniques**: Fast and slow pointers for cycle detection (Floyd's Algorithm).
*   **Dummy Node Architecture**: Handling tricky head-pointer boundary conditions cleanly.
*   **In-Place Modification**: Restructuring pointers directly without creating extra memory.

##  Code Standards
Every code file contains:
*   A link or reference to the original problem statement.
*   **Time Complexity**: Clear analysis (e.g., $O(1)$ updates, $O(N)$ lookups).
*   **Space Complexity**: Tracking auxiliary memory usage to ensure $O(1)$ overhead.
